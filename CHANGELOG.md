# История изменений

## v1.1.0 — 2 октября 2026

### Изменения

- Асинхронная передача файлов на Яндекс.Диск и ограничение параллельных загрузок.
- Поддержка фото, видео и документов с сохранением имён и расширений файлов.
- Сохранение полученных от Telegram байтов без перекодирования; для фото выбирается максимальное разрешение.
- Проверка настроек и доступа к Диску, создание папок при запуске и скрытие токенов в журнале.
- Ограничение размера файлов, повторы сетевых запросов и очистка временных файлов.
- Ожидание активных передач при остановке приложения.
- Исправленная сборка Docker с Python 3.13 и запуском без прав root.
- 89 тестов pytest, измерение покрытия и CI на Python 3.12–3.14.
- Пошаговые инструкции настройки, запуска и обновления.
- Автоматический выпуск GitHub Release с архивом Docker-образа после успешных проверок.

### Обновление с v1.0.0

- Для локального запуска требуется Python 3.12–3.14 и Poetry 2.5.1.
- Сохраните свой `.env`; обязательные параметры — `BOT_TOKEN`, `YANDEX_TOKEN` и `ALLOWED_IDS`.
- Папка назначения по умолчанию — `/bot_uploads`; она создаётся автоматически.
- Размер скачиваемого файла ограничен 20 МБ публичным Telegram Bot API.
- Новые файлы получают имена с ID чата и сообщения; старые файлы автоматически не переименовываются.
- Накопленные сообщения при запуске сохраняются; удаление можно включить через `DROP_PENDING_UPDATES=true`.
- Очередь передач не сохраняется на диске: после аварийной остановки незавершённые файлы может потребоваться отправить повторно.

### Файлы релиза

Рядом публикуется файл `.sha256` с контрольной суммой архива образа.
